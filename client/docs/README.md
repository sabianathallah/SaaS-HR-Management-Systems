## 🎨 Tech Stack

- React 19 + Vite 7
- Tailwind CSS 4
- React Router DOM 7
- Zustand (State)
- React Query (Server State)
- Axios (HTTP)
- React Hook Form (Forms)
- date-fns (Dates)
- Lucide Icons
